# 根据已测前沿分段观察（实验开关）

在含本目录构建覆盖的原生 ROS2 RACER 环境中，运行进程设置
`ASPIRE_FRONTIER_STEPS=1` 启用该选项。原有 `ASPIRE_KNOWN_TRANSIT=1`
可配合使用。没有场景坐标、初始朝向、预设航点或人员位置参数。

普通探索沿 RACER 选定前沿，在当前位置和前沿之间对称采样短途观察点。
评分结合向原生目标的进展，以及该位置朝向前沿时，视线不被已测障碍或未知体素
阻断的前沿样本比例。恢复时，同样的方法可在已测且未被当前恢复策略禁用的
位置中寻找中间观察点；找不到时回到原生恢复路径。有限采样只是选择候选，
并不保证能在给定时间发现所有区域或人员。

最终航迹仍须通过原生规划、执行通道、连续轨迹净空和末端制动检查。
授权时，若长航段不安全，尝试长度递减的原生轨迹前缀。仅保留连续检查通过
且可停车的前缀，不把未知视作自由空间。静止处衔接下一段时，将有限、有界的
累计航向写为等价的主值，保留角速度和角加速度；运动中的交接不在此处改写。
