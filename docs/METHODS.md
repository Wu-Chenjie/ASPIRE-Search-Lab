# 实际方法审计（2026-10-13）

结论：已有“感知—候选—复查—RACER 轨迹—实际仿真运动—确认”接口与运行证据，不只是添加 RGB 相机；新增人员搜索仍是工程启发式原型，不能包装成已复现的概率主动搜索论文。

| 模块 | 实际代码与方法 | 来源性质 |
|---|---|---|
| 基础探索与轨迹 | `external/racer_ros2_ws/src/racer_core/`：前沿、原生视点、分层网格/巡回、A*/动力学搜索、ESDF、B 样条与原 FSM | 迁移后的上游 RACER；当前只验证单机，不声称复现多机论文实验 |
| 人体语义 | `src/person_search/perception.py`：OpenCV 内置 Dalal–Triggs HOG＋SVM，2 倍图像，得分≥0.7 | 调用现成分类器，没有重训或复现原论文实验 |
| 几何候选/定位 | 同文件：相邻三维距离<0.10 m 连通；尺寸、非平面、内部像素条件；针孔反投影和采集时刻刚体变换；可见表面三维中位数 | 本任务工程实现；不是框中心深度、人体中心或遮挡后预测 |

| 执行与安全 | `annual_runtime/*`、`core/planning/{bspline_trajectory,handoff}.py` 和原地图/租约模块：精确原生曲线、制停、已知空间、动态约束、PX4 EKF2与Offboard | 从原工程精简复用；任务添加单机接口、可关闭复查和拒绝恢复 |

能确认的项目论文依据是 [RACER: Rapid Collaborative Exploration with a Decentralized Multi-UAV System](https://arxiv.org/abs/2209.08533)，对应源版权/引文保留在 `licenses/RACER-upstream-README.md`。没有证据表明新增人员搜索复现了其他具体论文；不得事后补引文来声称已有来源。

RACER 自身有基于地图前沿的探索视点评价。新增找人分支没有建立人员目标信念栅格、探测概率/漏检模型、遮挡后存在概率或期望信息增益；其 `confidence` 为检测得分，`semantic_views` 是计数，不是概率更新。完全隐藏时仅能继续基础探索。

ESARBench **未接入**（无适配器、其数据集或正式指标协议）；Visual Jev **未接入**（无调用或候选评分服务）。均不可列作已复现实验。

已有实验：四视角120对静态RGB-D；理想执行下原探索/侧移/主动视角各一次45秒；实际动力学下原FSM正负例及有限复查模式正负例各一次180秒。后者同时改变逐段执行和前沿拒绝恢复，不是纯策略消融，没有统计显著性结论。具体通过和失败见 `RESULTS.md`、两个 validation JSON。

## 94.5 秒正例的因果审计

`flight-active-01/telemetry.jsonl`：72.236 s 首段 `tracking_view`；75.185 s 人体 track 2 首次成为几何候选；75.989 s 首次语义命中，此时机体约 `[-0.120,-1.173,1.576]`；94.503 s 两视角确认。track 2 的 `attempts=0`，没有驱动复查请求。

`person_search.log` 的三次请求均为板边误候选 track 1。原生日志 1791884831.473343 UTC Unix 秒出现一次 `Task review planned`，1791884831.504770 紧接 `execution rejected`。因此该候选确实改变了一次规划提案，但其复查轨迹没有实际执行。该正例不能用于证明主动视角策略的发现贡献；其人体发现来自基础探索自然进入可见视角。通用拒绝恢复仍会改变后续原生前沿选择，但不是人体目标信念驱动。

当前应称“自主探索＋检测闭环”。目标导向主动搜索尚未经过执行路线因果验证。HOG 漏检时有独立的可见深度弱候选；若完全没有目标表面/弱线索，则没有目标特定的补看依据，仅继续基础探索。未来需显式记录候选ID→请求→原生提案ID→实际激活→新增目标证据，并用同配置无复查对照验证贡献。

第三阶段固定起点矩阵继续得到同样的因果结论：可见左起点在起飞扫描中确认；部分遮挡左右起点确认目标的 `attempts=0`，由基础探索提供新视角。关闭 RACER 最短时间优化和受限放宽执行包络用于稳定性验证，保留同一规划器；没有证明新增目标评分带来收益。飞行定位误差和独立真值隔离见 `PRECISION.md`，全部成功/失败记录见 `stage3-validation.json`。
