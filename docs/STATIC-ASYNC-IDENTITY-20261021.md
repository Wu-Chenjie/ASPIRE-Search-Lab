## 最小实现

Python producer 增加可选的本地 `identity_input_state`（pending/completed/unavailable）与 `identity_input_deadline_s`。状态绑定原 capture/frame，不赋予定位或确认权威；缺字段的旧消息为 unknown，保持原响应。completed 表示几何处理已完成，可能没有合格表面；unavailable 包括拒绝/失效。producer 和原生消费者都防止同捕获晚到 pending 覆盖已完成表面，视觉确认仍独立推进。

原生只在以下条件全部满足时暂缓昂贵预览：当前精确捕获明确 pending；前两次连续有效表面在原时窗和坐标系内；与当前捕获构成原 .4 秒跨度；沿用原 <.6m 代价及不加 surface margin 的不确定度重叠门；只有一个兼容锚点分量且该分量已确认；没有有效竞争来源/其他锚点/共现排斥。两帧只产生调度等待提示，绝不建立身份边、不提前确认、不产生可靠XYZ。正式身份关联仍需至少3个实际有效捕获和原.4秒跨度。

所有兼容锚点都参与竞争，包括未确认锚点；当前有效的其他未解来源也参与。min05 的来源4/15只有历史单帧，其当前输入已经超过原捕获有效期，所以不充当当前竞争观测；其历史、身份未知和锚点均不删除。旧协议未知有效期仍保守沿用原2秒测量TTL。没有调整空间误合并门。

暂缓到当前 producer 捕获有效期，原生最多允许 capture+0.75s，允许更短有效期。重复/乱序、同捕获新sequence、后续pending帧都不能续同一资格的期限。几何完成/拒绝、当前帧替换、歧义/排斥立即释放为unknown或由原规则关联并撤销。几何永不到时，FSM调用 `start(now)` 在截止后使原资格重新可选；无需新深度消息，也不抹掉短观测窗口。实际开始仍受原任务、安全和全局单计算槽约束，不能承诺截止时无条件执行。

新目标无两帧历史、弱线索、没有已确认锚点、legacy unknown、邻近歧义都正常响应。等待项不占计算槽，不阻挡其他新目标。一个真实新目标如果在现有证据下与已确认锚点不可区分，仍可能被短暂延迟，最长至该捕获截止；这是明确的未知边界，尚未用独立多人物数据校准。

未采用统一等深度、固定sleep、大缓冲、两帧提前合并或真值合并。导航资格与视觉确认仍独立于高精度定位。
