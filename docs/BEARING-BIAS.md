# Stage26历史方法 · 无深度人体方位证据与原生候选偏置

2026-10-16（UTC）。本目录是stage26单机活动源码。唯一研究记忆仍为[PROJECT_MEMORY.md](../../task-3/PROJECT_MEMORY.md)，实际运行和通过层级以[阶段报告](../../task-3-evidence/stage-26-bearing-bias/RESULTS.md)为准。该功能默认关闭，启用参数为`--bearing-bias`；当前拒绝在多机配置中启用，不宣称已改进RACER分布式任务分配。

## 语义、方位、定位与确认分层

RGB检测及基本支持充分时，即使深度缺失或三维定位拒绝，仍可生成方位候选。基本门为RGB置信度≥0.5、掩码至少40像素；连续3个不同采集时刻、2秒窗口内跨度≥0.4秒才向原生端发布持续证据。确认器原有的深度、掩码比例和质量门不用于阻断这一层，也未被降低。

使用采集时刻的RGB内参、相机到地图变换和检测框，计算世界坐标的光心、单位中心射线、四角射线及包围圆锥；不使用深度、人体坐标或场景真值。圆锥是图像框的几何包络，尚非经标定的不确定度或存在概率。`position:null`、`range_m:null`明确表示没有人体距离或位置。变换、内参、时刻不可靠时拒绝几何方位，仍保留二维语义记录。

方位ID按短时框重叠或角度/相机位移关联，仅代表搜索线索，不能作为独立人员ID。每次新图像先将该帧定位状态记为未定位，定位模块之后单独更新`localized_surface`或拒绝原因；不得沿用旧帧三维成功状态冒充当前成功。即使后来有表面位置，本评分仍仅使用射线，不把该点当成目标中心。

## 原生接入点与成本

`FastExplorationManager::planExploreMotion`保留原网格/前沿路径和原始下一视点；在原始`planTrajToView`之前调用`taskBearingRerank`。原目标始终作为基线，只考虑已有`ed_->points_`顶层前沿视点，按距当前位置排序最多评估8个有正角度效用的替代候选。未新增人体目标点、虚拟距离、Python规划器或手工绕障路径。原生恢复分支保持原规则，本轮偏置只作用于正常探索选择。

成本使用原生`ViewNode::computeCost`的时间型代价；仅将效用作为无量纲折扣：

```
C_adjusted = C_native * (1 - 0.5 * U), 0 <= U <= 1
U = confidence * angular_alignment * (1 - age/20)
    / (1 + completed_observation_coverage + previous_bias_selections)
```

`angular_alignment`在中心线处为1、圆锥边界及外部为0；候选朝向还须与相机视场和圆锥重叠。此项是启发式搜索效用，不是人体存在概率、信息熵或已验证收益。候选位置到光心的长度只是导航候选几何量，不是人体距离估计。

替代候选的原始成本不得超过基线1.5倍；最大折扣50%，不引入负成本。原目标路径不可达或无法验证时不覆盖。替代路径和终点必须在原生地图中已知自由且无膨胀占据；对路径每段加密到不超过5厘米检查，未知空间一律拒绝。之后仍走原生轨迹规划、授权、0.6米净空及执行安全门，偏置不能授权运动。关闭或无证据时不计算替代路径，原始目标保持原值。

## 有界回退

| 约束 | 冻结值与行为 |
|---|---|
| 消息TTL | 采集时刻起20秒；将来/过期/畸形数据拒绝 |
| 单线索偏置次数 | 最多2次；刷新图像不清零 |
| 全任务偏置次数 | 最多4次；新ID也不清零 |
| 活跃时间预算 | 首次考虑新鲜线索起60仿真秒，不随更新刷新 |
| 几何探索机会 | 每次改变选择后，下一次强制使用原始探索目标 |
| 观察衰减 | 只有实际完成、token一致、时间匹配且相机方向重叠的观察证明增加覆盖计数；每token至多一次 |
| 线索内存 | 每任务最多64个角度线索，避免别名无限增长 |

无线索、过期、不可达、成本超限、效用不足和预算耗尽均回到原始选择；没有必要也不能据此判定区域无人。本轮采用次数/时间/成本上限限制误导和无进展，不另实现已校准的“无进展概率”。重复看到同一人、错检及关联断裂均可能产生多个线索；上述全任务上限防止靠换ID无限重启。

## ROS接口及时间语义

| 话题 | 类型与用途 |
|---|---|
| `/search/semantic_candidates` | 原有String JSON，二维语义候选及定位结果 |
| `/search/bearings` | String JSON；射线/圆锥、采集/处理时刻、支持帧、定位状态及角度线索ID |
| `/search/bearing_evidence` | Float64MultiArray；固定map坐标、版本1、17个double，持续方位的原生输入 |
| `/search/bearing_decision` | String JSON；原生接收、候选评分/选择、对应规划结果，用于离线追踪 |

数值消息索引：`0`版本，`1`来源UAV，`2`方位ID，`3`采集秒，`4:7`光心XYZ，`7:10`单位射线，`10`圆锥半角弧度，`11`置信度，`12`支持采集数，`13`完成观察覆盖数，`14`本帧表面定位标志，`15`当前支持窗口首采集秒，`16`相机水平半视场角。当前仅接受本机UAV 0来源；这不是已完成的多机共享协议。

原生接收日志记录输入17项、处理时刻和接受与否；决策记录原目标/选中目标、候选ID、原始及折扣成本、效用、可达标志、线索ID和预算。规划结果另记请求目标及实际曲线终点；短曲线终点不等于到达远处请求目标。用原生plan ID关联实际执行token、位移、完成/制动和后续观测，不能仅凭`changed:true`宣称成功飞到或完成确认。

确认日志将“有语义但无可靠定位”与“无语义候选”分开，并记录连续计数清零前后值及采集/处理上下文。主动观察的新帧边界使用实际到达事件时刻；处理收到该事件的时刻另存。旧报告及原日志不重写，确认质量条件保持原值。

## 验证和复现

原生策略测试编译实际使用的`bearing_bias.hpp`，覆盖无证据基线、朝向偏好、不可达拒绝、TTL、关闭、覆盖衰减、任务上限与别名、60秒耗尽和非法输入。Jazzy接口测试完全不发布深度，只注入RGB/内参/采集时刻估计位姿与TF，检验持续未定位方位输出；该fixture不等于YOLO实测或新飞行。

`bearing_replay.py`读取旧保存掩码、内参和同帧TF，重放方位记忆，缺失TF直接跳过；不以最新位姿补配、不重新跑检测、不生成运动。`bearing_decision_audit.py`将实际保存的原生接收/候选输入重新送入相同C++策略，核对接收、成本、选择及预算；它不重新验证路径，也不替代执行安全审计。

本轮冻结协议仅两次动力学：同一stage25部分遮挡场景、原档动力学、相同YOLO模型和hybrid确认器、相同180仿真秒，偏置关闭/打开，主动复查及其续段均关闭以隔离变量。正常人体、背景负例、不可达和误导线索中的其他组合未在本轮做完整动力学矩阵，分别按单元/接口/旧帧回放证据标注。一次开关对照最多说明机制是否被触发及个例效果，不证明人员召回或统计优势。

容器复现命令由阶段证据中的`setup.sh`和`flight.sh`锁定；不直接使用历史README的旧构建路径。每轮使用新输出目录，记录源码与原生二进制哈希、保存证书、视频及失败。不得为本轮通过降低确认门、净空或修改场景。
