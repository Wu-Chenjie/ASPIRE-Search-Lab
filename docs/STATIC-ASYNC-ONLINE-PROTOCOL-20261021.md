# 单次异步就绪在线验收协议

算法基于9b1bb1e；本提交只增加默认关闭、旁路只写的因果观测，保留检测/确认、安全200ms、240仿真秒、2100wall、单轮2GB、磁盘8GB余量及文本32MB合同。仅一次同minimal-l-c3工程场景真实感知动力学，不扩配对、不注入候选/轨迹/深度丢失、不延迟确认。每个run ID只能启动一次。

ASPIRE_NATIVE_CAUSAL_JOURNAL开启原生定长journal，初始化时独占创建/预分配/触页，128字节头+8192*80字节记录=655488字节。回调仅定长复制，无JSON、动态分配或逐记录写盘系统调用；满后记dropped，不覆盖原记录。映射写仍有内存、锁、时钟和内核页回写开销，不能称零I/O成本或硬实时保证。异常建档使原节点初始化失败，不放行无观测启动。

小端uint64头：magic=0x4153504952454331/version1/capacity/written/dropped/row_words10/header_words16，其余保留。每行：ordinal、sim_ns、steady_ns、kind、callback_id、source_counter、sequence、capture_ns、a、b。kind1为local回调首部时钟（a=原消息字节数），2为实际接受输入（a=unknown0/pending1/completed2/unavailable3，b位0=合格表面、位1=该来源自身已确认），3为处理发布结束（a=接受条数），4为回调错误。kind10=等待建立（a=deadline_ns），11=计算准入（a=token/b=generation），12=等待释放（a=原deadline/b=确认1、输入或拓扑变化2、截止3）。callback1/2/3经callback_id绑定；源与序列再关联原producer/registry日志。单机器人单会话范围，不能直接当跨机器壁钟。sim采样与steady采样是紧邻操作而非同一个原子时钟；ordinal为记录锁顺序，跨线程以steady采样与字段解释，不能无条件当物理事件全序。

预检：原服务器无重复运行/构建/测试、源码与ELF哈希一致、当前空间足够、旧监督故障回归通过。记录满/字段错/缺回调结束/运行异常均如实列证据缺口。Mac开启记录的全部异步对抗合同结果必须不变；原WSL严格协议、原生构建及实际记录成本必须通过。不得在动力学期间并行编译、回放或真值审计。

在线主要条件：
1. 首次新目标不受统一几何等待；若恰好无pending窗口，只报告自然覆盖不足。
2. 与已确认实体的保守历史关联支持成立且同帧几何pending时，应有等待建立；等待期间不能取得新计算token/昂贵preview/planning/submission。完成后按原身份门关联撤销或按unknown放行。
3. 深度永不到时截止后原资格可选；本轮仅统计自然出现，未出现则保留原组件回归，不制造丢帧来声称在线覆盖。
4. 在线确认身份与离线真实人物核对；unknown不强行合并。并发峰值1，取消/失效及最终进程和磁盘监督正确。活动取消若无自然窗口，不冒充通过。
5. 原min05只作事件机制参照，不能将不同轨迹/观察中的原始任务数差异称收益。一次结束先审计，失败给确切原因，不自动连续重跑。

观测预检：Mac463/38；WSL定向23/0。原275HX记录调用disabled均值19.52ns、enabled52.29ns，enabled p99 58ns/采样max30600ns；不含ROS now()调用、完整回调和系统最坏负载。开启记录的既有min05回放仍为1次准入（旧基线5），整体sync均值7.75us/采样max397.16us，未把噪声视为收益。历史200ms与独立校准仍未解决。
