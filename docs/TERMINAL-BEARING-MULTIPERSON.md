## 2. 最小修复及安全边界

参考到达原曲线终端后，进入独立的`terminal_hold`检查，不设置`arrived`，不产生观测回执、不改轨迹，不追加位移，也不获得探索收益。授权条件同时满足：

- 参考进度确实等于原终点，参考位置与固定原终点一致；终端导数和小于现有1e-5停止容差。
- 原`.1m`估计跟踪管、`.6m`物理净空、原生与mapper双地图已知自由/膨胀检查继续生效，未知空间仍阻断。
- 地图年龄不超过原1秒，检查耗时不超过原`.2s`，年龄加计算延迟仍不超过1秒。当前硬故障先于所有保持早退检查。
- 每条激活曲线第一次到终端时锁存等待起点；新地图、重复检查都不能续期。借用观测模块现有1.5秒有效窗作为本阶段新增的保守等待预算，不声称这是原RACER要求。超时、时钟回退、未知/占据根点、参考仍运动、参考点改变、失效地图均拒绝。原移动制动绝对截止时间不改。

`.05m`触发仍被记录；已经零导数的参考无需另造制动段。之后每个控制tick仍检查实际估计跟踪管。真正`arrived`仍只由原`ObservationCompletion`证明：到达之后实际处理的深度整合帧、原`.07m/.12rad`视角门及原时效/网格/会话约束。取消、新激活和新的制动替换清除终端等待状态。

在线首次终端许可保存独立`terminal_hold`地图证书，执行报告继续提供锁存起点/截止/当前检查状态。离线审计重建固定终端、导数、双地图、跟踪误差和时间，不信任伪造的新鲜度字段。该证书不计作新制动，也不能替代全程安全证明。

## 4. 进程退出顺序

[冻结协议](../../task-3-evidence/stage-33-terminal-bearing-multiperson/protocol-frozen.json)先于启动写入。A批最多3轮，每轮180sim秒、600wall秒；原点/估计odom截止120wall或30sim、起飞截止180wall或60sim。单人先行，并要求至少有激活和终端保持证书且审计无故障，再进入邻近双人、遮挡三人。实际飞行器始终1架，多人不是多机。

任何安全/启动/进程故障立即停止本批余轮，不重启已尝试编号。只有发现独立具体实现缺陷、完成新修复和新回归、另行声明B批，才允许条件性新批次；至多一次、合计动态尝试不超过6轮。不能靠放宽跟踪/地图/质量门或更换好看的场景强过。
