# 定位口径与飞行约束审计

输出坐标是**可见人体表面内部像素反投影的三维中位数**，不是人体中心、脚点或遮挡后的推断位置。跟踪器再对关联观测求均值，因此单帧定位与最终轨迹标记也不是同一个统计量。

## 静态四视角

`tools/flight/localization_audit.py` 独立解析实际人体网格，使用相同相机内参、姿态和候选内部像素逐三角形计算光线交点。真值仅离线使用。比较实际输出与这些交点的中位数；约 0.2–0.4% 的模型边缘未匹配像素不进入真值中位数。

| 视角 | 已保存帧数 | 几何定位 / HOG 人体命中 | 表面三维误差 |
|---|---:|---:|---:|
| 可见 | 1 | 1 / 1 | 2.654 mm |
| 部分遮挡 | 1 | 1 / 0 | 2.504 mm |
| 完全遮挡 | 1 | 0 / 0 | 无输出 |
| 侧移显露 | 1 | 1 / 1 | 4.220 mm |

三个几何样本误差中位数 2.654 mm、最大 4.220 mm。部分遮挡的语义检测漏检必须保留，不能把几何候选算作发现人数。不同视角输出 XY 最大分离 0.203 m，对应真实可见表面的变化约 0.202 m；不能把这一变化当作同一点的定位漂移。

这些数值只审计理想已知静态位姿下的投影链。单像素深度残差最大仍有 6–14 cm，三维中位数抑制了边缘离群值。120 对时间戳检查不是 120 个已保存定位样本，也不能据此声称飞行毫米级精度。

## 动力学拒绝原因

`tools/flight/audit.py` 对原始 RACER B 样条做连续多项式峰值计算，并与 2 ms 数值采样比较。旧 `flight-active-01` 的 185 个提案中，速度、加速度、jerk、yaw 超限分别为 134、31、70、1 次，可重叠。峰值最大为 4.797 m/s、8.995 m/s²、25.879 m/s³、0.856 rad/s。解析峰值与采样差最大约 0.014，不支持“大量拒绝仅因单位换算错误”的解释。

原生优化器的名义限制是软约束；最短时间优化可能产生远超名义上限的曲线。控制权仍必须由精确曲线审查授予，不能把 PX4 参数默认值当作轨迹安全证书。

| 配置 | 原生名义 v / a / jerk / yaw | 执行器硬上限 | 最短时间优化 |
|---|---|---|---|
| legacy | 0.3 / 0.4 / 2 / 0.325 | 0.6 / 0.8 / 2 / 0.65 | 开 |
| moderate | 0.3 / 0.4 / 4 / 0.325 | 1 / 1.2 / 4 / 0.9 | 开 |
| consistent | 0.3 / 0.4 / 4 / 0.325 | 1 / 1.2 / 4 / 0.9 | 关 |

对应单位为 m/s、m/s²、m/s³、rad/s。新配置只用于有界仿真验证，默认仍是 legacy。没有放松占据、未知空间、制停、时效、坐标帧、有限值和飞行故障检查；未改 PX4 性能参数。`consistent` 仍使用同一个 RACER 规划器及 B 样条优化器，不做理想运动或执行时重定时。

飞行精度由 `tools/flight/flight_localization.py` 另行审计：原生 Gazebo 位姿仅进入独立记录器，按时间括号插值并补偿机体模型原点至 base_link 的 0.24 m 偏移，再分解相机位姿误差贡献和深度/栅格残差。两项误差模长不能直接相加。样本为每约 5 秒保存的相关帧，不是独立重复试验。

首次完整飞行真值审计 `matrix-visible-left`：32 对保存帧，7 个符合表面匹配要求的几何观测，其中 3 个带 HOG 命中。总表面定位误差中位数 **0.08765 m**、最大 **0.29118 m**；位姿误差贡献中位数 **0.08838 m**、最大 **0.29284 m**；深度/栅格残差中位数 **0.00258 m**、最大 **0.00364 m**。这说明飞行位置标记的主要误差来自机体位姿估计，而不是框中心取错板深度。这里最大误差来自几何候选，不能直接当作已确认标记误差分布。

同批 32 帧的机体位置误差中位数 0.0452 m、最大 0.2605 m；姿态误差中位数 0.772°、最大 5.173°。目标在数米外时，较小的角度误差也会明显放大地图坐标误差。尚无真实室内定位或误差置信区间保证。
