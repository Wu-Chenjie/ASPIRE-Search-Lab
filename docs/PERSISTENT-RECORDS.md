## 2. ID、状态与计数

| 层次 | 实际意义 | 限制 |
|---|---|---|
| 短视觉ID | 同一相机短时IoU轨迹 | 不是跨视角真实人员 |
| 源记录ID | (robot,session,counter)，session为视觉节点UUID | 非中央分配的全局人员ID |
| 本地对应组 | 可撤销连接；代表键取组内最小源键 | 成员变动可改变代表键，不是全局永久身份 |
| 独立真实人员 | 由独立评测匹配 | 在线自动字段始终null |

视觉状态person_candidate/visually_confirmed与定位unknown/unreliable/reliable/expired分开。可靠测量还须满足当前时间租期；历史好点不冒充当前点，定位失败不撤销视觉历史。视觉门沿用Stage30：置信度≥.70、5个不同采集时刻、跨度≥.8秒及既有短时关联。直接确认不等待两次主动视角。

## 3. 保守空间对应

候选逐条枚举，仅使用同一可靠frame/version下的当前点或明确静态历史表面锚点。跨机器人还须两端声明shared_aligned。距离门为min(.8,radius_a+radius_b+.35)；仅整个候选关系简单、唯一且距离成本<.6时连接，竞争则拒配，不凑人数。草案的.15差值门未实现，实际采用更保守的唯一候选或拒配。

同robot/session同帧不同轨迹形成cannot-link；摘要传同源counter排斥集合，迟到记录也应用。坐标、几何或共存冲突能撤销连接。约束依赖检测/NMS，检测框共存不能证明真实人数。

相近射线不形成强身份连接；无可靠定位的远处重入画可能仍无法关联。导航邻域共享预算与人员身份合并是两回事。每机器人最多128记录、总计256、最多2机器人；每源32个不同采集时刻历史。候选扫描之外还有连通关系重算，不能声称总体严格O(N)或Orin NX已实测。

## 4. 独立可见表面定位

surface.py在腐蚀掩膜中对有效深度做4连通组件，相邻差≤.12m；保留主要且核心支持充分的组件，拒绝相近竞争组件。冻结SurfaceConfig与测试覆盖混合背景、歧义组件、缺深度、恢复/丢失和弱关联拒绝。

同一短时源至少3个合格表面样本、跨度≥.8秒、窗口2秒、离散≤.25m才能有当前点。代表点是保留可见表面的时间中位数，不是中心、脚点或稳定解剖点。像素离散与.05m位姿底形成模型协方差，3σ半径须在[.05,.4]m，超出则拒绝，不截断；不是已校准的中心误差界。

新RGB缺当前深度/TF时清空点，晚到旧几何不能挂到更新视觉帧。旧好点带原时间/history_only保留。相机标定、位姿估计、坐标对齐和人体定位分别有误差。跨源不数值融合点、不自动缩小协方差，只选择最新合格源。精度审计用同一保留像素处的真实人体网格表面，报告污染/缺真值/拒绝。

## 5. 原生有限收益与失败记忆

| 约束 | 实现 |
|---|---|
| 当前方位 | 2秒有效，无可靠TF/标定不造世界射线 |
| 额外价值 | 固定发现epoch起线性衰减，20秒精确为零 |
| 不续期 | 普通帧、新短ID、重传、仅地图时间戳变动 |
| 实质变化 | 相机平移≥.5m且世界方位变化≥5°；或首次合格定位；或固定邻域≥6个不同体素新变自由 |
| epoch更新 | 最多1次，距原epoch至少5秒 |
| 失败邻域 | 原点≤.75m、方向角≤.20rad，共享导航预算，不强合并人员 |
| 失败 | 不可达、规划失败、执行拒绝、观察完成仍无首次定位进展 |
| 冷却/重试 | 15秒且有实质变化；时间单独不解锁；最多1次实质重试 |
| 新评估界 | 每导航组2次，全任务扣减合计8次；一次重排可扣多个组 |
| 原改选界 | 每cue/共享组2次，全局4次/60秒，改选后保留原探索机会 |
| 原路径计算界 | 每次最多8条额外候选路径，成本不超过原目标1.5倍 |

原生仅将首次合格定位记作定位进展；普通revision、共存约束或已有点重发不算。一般质量改善尚未单独标定成收益。地图采样按实际体素去重，新自由证据仍须通过路径/执行安全门。

零价值、失败、撤回或耗尽时不生成额外观察候选，回普通RACER；不截断已授权安全段，不判区域无人。相邻真实人员可能共享预算，是保守召回风险。

## 6. ROS接口与通信口径

显式confirmation_mode:=registry，SITL用--confirmation-mode registry，可另开--bearing-bias。此模式抑制旧Python数值方位，C++直接向同一原生策略供元数据；没有新增外部数值v2包。

| 话题 | 用途 |
|---|---|
| /{robot}/search/target_observations | String/schema1同帧观测批次 |
| /search/target_summary | String/schema1源记录事件摘要 |
| /search/target_sync_request | 有界分页 |
| /{robot}/search/person_records | 本地富状态、schema_version3 |
| /{robot}/search/target_registry_events | 记录/连接/撤销/拒绝 |
| /{robot}/search/targets | C++当前点或无距离射线 |
| /search/tracks、presence_events | Python短时源/视觉确认，不是独立人数 |
| /search/bearing_decision | 原生选择、计划关联、失败账本 |

sequence与实质record revision分开；源键/首次时间不变。重复/旧revision忽略，采集时间不可倒退。外来源不再广播，无中央唯一注册表，无图像/外观向量摘要。

摘要是最近实质快照，未逐帧发送持续可见心跳；对端可能将长期静止但仍被本机观察的点标为过期，仍保留静态锚点，不能称实时共享所有观测。原生引导只用本机新鲜射线。

每请求≤8条本源记录、≥1秒间隔、请求ID去重保留64条；摘要发送≥.2秒间隔，分页与普通事件轮流。历史字段after_counter实际为排序条目偏移，非counter数值，避免多session漏页。周期同步不是原子全局快照。

只统计实际String UTF8负载和同步请求字节；DDS头/重传/发现、无线链路、RACER其他协作话题、远程调试图像/富状态不在内，不能宣称整机通信量降低或双机协同收益。

## 7. 时效与验收层次

生产timer仍.2仿真秒，原2线程executor、sensor_data QoS与40帧队列不改。记录到达/独立消费、采集/处理、墙钟接收年龄与推理耗时；主动取最新帧不等于DDS丢包，积压/过期/吞吐另报。选择器只取满足原时间门限的帧，最新未来帧不能饿死已有效帧。

原速及各失败保留；慢时钟语义夹具不能代表真实频率达标。新增process_calls未正确递增，是测量缺口；到达/消费计数仍可算频率，本批不轮间改源码。

完整回归仍有新模式定位时效失败；实际两轮已结束，第二轮未起飞/watchdog，第三轮按停止规则未启动，整体未验收。模块、保存回放、双源ROS、原生夹具、SITL不能互相替代，也不冲销Stage27故障。
