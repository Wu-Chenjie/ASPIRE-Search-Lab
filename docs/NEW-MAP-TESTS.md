## 人员诊断与限制

人体位置先按原扫描地面和无碰撞检查固定，未依据检测结果或飞行结果移动。静态相机只是传感器夹具，不能称自主搜索。首轮 rsgg 全显露及侧移视角检出、定位并合并为一个确认目标，无人负例零检出；初设部分遮挡视点实际全隐藏，保留失败并用几何边界重新选取静态视点。k1cup 初设全显露视点被桌上植物遮挡，而安全侧视点有真实 YOLO 检出；不降低检测阈值来改判。
